## Overview
Inevitable Infotech Pvt Ltd is an Ahmedabad-based software testing and QA company (founded by Bhavan Thakor and co-founder Nilofar Jargela) that also offers software development, mobile app development, and on-demand IT resourcing. Services include manual testing, automation testing, software test consulting, performance testing, and API testing.

**Founder (per podcast):** Further corroborated by a dedicated TEG-branded podcast episode — "Tech Talks at Gujarat Tech Expo 2024 | Ep 17: Nilofar From Inevitable" (Chai Time with ManthanBaba) — which features **Nilofar**, matching co-founder Nilofar Jargela already on record above.

## Company Details
- Founded 2018 or 2019 (sources differ; not reconciled).
- Headquartered in Ahmedabad, Gujarat, India.
- 77 employees (as of April 2026); estimated $1M–$5M annual revenue.
- Certified ISO/IEC 27002; reports a 100% project delivery rate.
