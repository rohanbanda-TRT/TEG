## Overview
ONBBITS is a conversational-commerce platform that automates customer conversations via the official WhatsApp Business API — chatbots, broadcasts, a shared team inbox, and analytics. It targets Indian SMBs that already use WhatsApp but do not leverage it effectively for commerce. (Task described the company as "software development"; public sources describe it specifically as a WhatsApp Business API / automation product.)
