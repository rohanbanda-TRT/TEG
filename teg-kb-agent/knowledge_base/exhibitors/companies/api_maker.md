## Overview
API Maker is a no-code backend development framework — self-described as "the framework for AI era" — designed to eliminate repetitive backend coding tasks so developers can build and maintain software faster and more cheaply. It is developed and maintained by SAVA Info Systems Private Limited, which has itself been API Maker's primary customer since 2021, using it for custom software development.

## Company Details
- The API Maker project launched June 9, 2019.
- Headquartered in Ahmedabad, Gujarat, India — Office 4 & 6, Gangotri Shopping Center, New Ranip, Ahmedabad – 382480.
- ISO 9001 certified.
- Parent/operating company: SAVA Info Systems Private Limited.
