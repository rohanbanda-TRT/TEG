## Overview

Identified with confidence. The official Tech Expo Gujarat exhibitors page links the "Tisha" sponsor logo directly to **tishatechnologies.com** — the exhibitor is **Tisha Technologies**, a web and mobile application development agency (iPhone/Android app development, web design, e-commerce, AR/VR, IoT). This is very likely the same company as "Tisha Tech," the small Ahmedabad-based mobile app development firm (established 2016, Gujarat GST proprietorship) previously surfaced via The Manifest — the brand name, city, and service line (mobile app development) all align, though the fetched tishatechnologies.com homepage itself did not restate an Ahmedabad address to independently confirm this is the identical legal entity. It is unrelated to "Tisha International" (Ahmedabad laptop-hardware retailer), which is ruled out as the TEG exhibitor.

**Founder (per podcast):** Further corroborated by a dedicated TEG-branded podcast episode — "Tech Talks at Gujarat Tech Expo 2024 | Ep 3: Parth Mehta, Tisha Tech" (Chai Time with ManthanBaba) — which names **Parth Mehta** as the founder/leader of "Tisha Tech," directly matching the "Parth and his team" reference already on this file and the exhibitor name "Tisha." This independently confirms the Tisha Tech ↔ Tisha Technologies identification.
